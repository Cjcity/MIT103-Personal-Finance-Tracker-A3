
# Personal Finance Tracker – Assessment 3

MIT103 – Fundamental Programming Concepts  
Student ID: MLB0000637

## Project Overview
This project extends the Personal Finance Tracker
developed in Assessment 2 using Python.

## Features
- Add, display, search and delete transactions
- CSV file storage and restoration
- Admin and Viewer user roles
- Role-based access control
- Salted PBKDF2 password verification
- Input validation and exception handling
- Category-based financial summaries

## Technologies
- Python 3
- Google Colab
- CSV file handling
- Git and GitHub

## Security
The repository uses fictional financial data.
Real passwords and financial records must not
be committed to GitHub.
